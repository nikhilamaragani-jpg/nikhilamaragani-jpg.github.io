The original Campfly Sales Analysis and Netflix Analysis dashboards are retained as learning/workshop evidence. Their PDF export is a historical static artifact, and their displayed figures should be treated as source-display values rather than newly validated business findings.

These workshop dashboards are supporting evidence. The Olist flagship is the primary Power BI/BI portfolio project.

## Portfolio standard

For a recruiter-facing Power BI project, the preferred evidence set is:
- Real or clearly labeled practice data
- Explicit KPI definitions
- Controlled table grain
- Interactive filtering
- Reusable measures
- Clear insight narration
- Data-quality checks
- Reconciliation between analysis and dashboard results
- Honest project-status wording
